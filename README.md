# Graph Transliterator Workspace

This is a monorepo workspace for the Graph Transliterator project.

## Repository Structure

- `packages/graphtransliterator-py/` - The core Python package and documentation.
- `packages/graphtransliterator-ts/` - (Upcoming) TypeScript/Vite npm module.

## Development Setup

This workspace uses Python Poetry for managing the development environment.

```bash
# Install all workspace dependencies and link packages
poetry install
```
